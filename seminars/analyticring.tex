\subsection{Condensed Math}
Let's start with a review of condensed mathematics. We would like to do topology and homological algebra simultaneously, but this is not possible classically. For example, the category of topological abelian groups does not form an abelian category: one can embed $\RR$ with the discrete topology into $\RR$ with the usual topology, and there is no reasonable cokernel for this map.

The solution to this classical problem proposed by condensed mathematics is to embed topological abelian groups into a larger category.
\begin{definition}[light]
	A profinite set is \textit{light} if and only if it is separable.
\end{definition}
\begin{remark}
	Due to compactness, separability is equivalent to being first countable. It also happens to be equivalent to metrizability, and it is equivalent to being an inverse limit of finite sets indexed by $\NN$.
\end{remark}
\begin{definition}
	A \textit{covering} of a light profinite set is a finite collection of jointly surjective light profinite sets. A light \textit{condensed set} is a sheaf on the category of light condensed sets. We let $\mathrm{Cond}$ be the category of condensed sets, and we let $\mathrm{AbCond}$ be the category of abelian condensed sets.
\end{definition}
\begin{remark}
	To give a condensed set is to give a presheaf $\mc F$ on light profinite sets for which $\mc F(S\sqcup T)=\mc F(S)\times\mc F(T)$, and any surjective covering $S\onto T$ induces
	\[\mc F(T)=\op{eq}(\mc F(S)\to\mc F(S\times_TS)).\]
\end{remark}
\begin{example}
	For any topological space $X$, there is a condensed set $\mathrm{Mor}_{\mathrm{Top}}(-,X)$. Similarly, an abelian topological group defines an abelian condensed set. The functor from topological spaces to condensed sets is fully faithful on a large subcategory (e.g., metrizable, compactly generated, Hausdorff spaces).
\end{example}
We now pass to solid condensed sets. The adjective ``solid'' is intended to force us to work with nonarchimedean geometry. For motivation, note that a sequence $\{x_i\}_i$ in $\RR$ (or any metric abelian group) which is summable is automatically a null sequence, but the converse need not hold. However, the converse does hold over $\QQ_p$. Thus, we will want to say something about convergence.
\begin{notation}
	Fix a condensed set $S$. Then define $\ZZ[S]$ as the sheafification of the presheaf
	\[T\mapsto\ZZ[S(T)].\]
\end{notation}
\begin{notation}
	We fix $P\coloneqq\ZZ[\NN\cup\{\infty\}]/\ZZ[\{\infty\}]$, where $\NN\cup\{\infty\}$ is the one-point compactification of $\NN$. The continuous map $(+1)\colon\NN\cup\{\infty\}\to\NN\cup\{\infty\}$ induces an automorphism $[1]\colon P\to P$.
\end{notation}
The moral is that $P$ represents null sequences.
\begin{lemma}
	Fix a topological abelian group $A$. Then $\op{Hom}(P,A)$ is equivalent to the group of null sequences in $A$.
\end{lemma}
\begin{proof}
	Look at where each point goes. By construction, $P$ sends $\infty$ to $0\in A$.
\end{proof}
\begin{lemma}
	The condensed abelian group $P$ is projective.
\end{lemma}
\begin{proof}
	Expand out the definitions.
\end{proof}
\begin{definition}[solid]
	A condensed abelian group $A$ is \textit{solid} if and only if the map
	\[({\id}-1)\colon\op{Hom}(P,A)\to\op{Hom}(P,A)\]
	is an isomorphism.
\end{definition}
\begin{remark}
	Intuitively, ${\id}-1$ on null sequences is given by
	\[(a_0,a_1,\ldots)\mapsto(a_0-a_1,a_1-a_2,\ldots).\]
	This is inverted by some telescoping map, which is where summability enters the picture.
\end{remark}
\begin{example}
	It turns out that $\ZZ$ is solid. The idea is that a null sequence in $\ZZ$ eventually vanishes and is thus summable. This shows that solid condensed abelian groups does not form a $\otimes$-ideal.
\end{example}
\begin{remark}
	The full subcategory of solid condensed abelian groups is stable under limits, colimits, and extensions.
\end{remark}
\begin{example}
	The forgetful functor from solid condensed abelian groups to abelian groups admits a right adjoint. For example, the solidification of $\RR$ vanishes.
\end{example}
\begin{remark}
	The functor from the derived category of solid condensed abelian groups to condensed abelian groups is fully faithful, and the image is given by those complexes with solid cohomology groups. For example, if $C$ is solid, then for any condensed abelian group $A$, the complex $\mathrm{RHom}(A,C)$ is solid.
\end{remark}

\subsection{Analytic Rings}
Here is our definition.
\begin{definition}[analytic ring]
	An \textit{analytic ring} is a pair $(A^\vartriangle,D(A))$, where $A^\vartriangleleft$ is a condensed ring and $D(A)\subseteq D(A^\vartriangleleft)$, for which
	\begin{itemize}
		\item $A^\vartriangleleft\in D(A)$,
		\item $D(A)$ is stable under limits and colimits (and so $D(A)\subseteq D(A^\vartriangleleft)$ admits a left adjoint $F$),
		\item for any $C\in D(\mathrm{CondAb})$ and $M\in D(A)$, one has $\mathrm{RHom}_{\mathrm{CondAb}}(C,M)\in D(A)$, and
		\item $F$ sends connected objects to connected objects (namely, $D(A^\vartriangleleft)^{\le0}$ goes to $D(A^\vartriangleleft)$).
	\end{itemize}
	Without the first condition, we may refer to $(A^\vartriangleleft,D(A))$ as an \textit{uncompleted analytic ring}.
\end{definition}
\begin{example}
	Our discussion of solidity shows that $(\ZZ,D(\mathrm{SolCondAb}))$ is an analytic ring.
\end{example}
\begin{example}
	There is an analytic ring with $A^\vartriangleleft=\RR$ and $D(A)$ given by the ``liquid'' condensed abelian groups.
\end{example}
\begin{example}
	For any condensed ring $A$, one can take $D(A)\coloneqq D(A^\vartriangleleft)$.
\end{example}
\begin{example}
	There is an analytic ring attached to any Huber ring $(A,A^+)$.
\end{example}
\begin{remark}
	The second condition implies that $D(A)$ is symmetric monoidal, and the functor $F$ is symmetric monoidal. The idea is to show that $\ker F$ is a $\otimes$-ideal. Well, for $B\in\ker F$ and $C\in D(A^\vartriangleleft)$, we must show that $F(B\otimes C)=0$. This is equivalent to checking $\op{Hom}_{D(A)}(F(B\otimes C),E)=0$ for any $E\in D(A)$, but
	\[\op{Hom}_{D(A)}(F(B\otimes C),E)=\op{Hom}_{D(A^\vartriangleleft)}(B\otimes C,E)=\op{Hom}_{D(A^\vartriangleleft)}(B,\op{Hom}_{D(A^\vartriangleleft)}(C,E)).\]
	We will thus be done by the free--forgetful adjunction if we can show that $\op{Hom}_{D(A^\vartriangleleft)}(C,E)$ lives in $D(A)$. Well, it suffices to show this where $C$ is a set of generators of $D(A^\vartriangleleft)$, for which we can take to be objects of the form $A^\vartriangleleft\otimes_\ZZ S$, and now we are done by the second condition.
\end{remark}
The last thing we will talk about today is colimits.
\begin{theorem}
	Colmits exist in the category of analytic rings.
\end{theorem}
\begin{proof}
	First, one shows that colimits exist in the category of uncompleted analytic rings. The underlying condensed ring is given by taking the underlying colimits, and the underlying derived catgegory is the subcategory of objects which land in the derived category of each component.

	Second, one shows that the forgetful functor from analytic rings to uncompleted analytic rings admits a left adjoint, so the right adjoint will give us our colimits. We will merely give the construction: for an uncompleted analytic ring $(A^\vartriangleleft,D(A))$, simply replace $A^\vartriangleleft$ to its image along the free functor $D(A^\vartriangleleft)\to D(A)$.
\end{proof}
\begin{example}
	Fix an analytic ring $(A^\vartriangleleft,D(A))$, and let $B^\vartriangleleft$ be a condensed $A^\vartriangleleft$-algebra such that $B^\vartriangleleft\in D(A)$. Then $(B^\vartriangleleft,\mathrm{Mod}_{B^\vartriangleleft}D(A))$ is the colimit of the following diagram.

\subsection{Six Functors on Analytic Rings}
The first part of the talk was given by David.

Last time, we defined an analytic ring as a pair $(A^\vartriangleleft,D(A))$ satisfying some properties. We start by remarking that $D(A)$ is more important than $A^\vartriangleleft$.
\begin{example}[categorical K\"unneth]
	Fix a diagram $A_\bullet$ from an index category $\mc I$ to the category of analytic rings, and let $(A^\vartriangleleft,D(A))$ be its colimit. Last time, we checked that
	\[D(A)\cong\colim_iD(A_i),\]
	where the colimit is taken in the category of presentable categories. However, the underlying $A^\vartriangleleft$ had to be modified rather significantly from $\colim_iA_i^\vartriangleleft$. 
\end{example}
\begin{remark}
	Colimits can be turned into limits. In short, by the Adjoint functor theorem, the internal morphisms $(A^\vartriangleleft,D(A))\to(B^\vartriangleleft,D(B))$ have $D(B)\to D(A)$ with a left adjoint $D(A)\to D(B)$. (In short, the adjoint is given by completing $(-\otimes_{A^\vartriangleleft}B^\vartriangleleft)$.) Then reversing all arrows turns colimits into limits. For example, one finds that
	\[D(A)=\lim_iD(A_i)\]
	after enough abuse of notation.
\end{remark}
Our present goal is to produce a six-functor formalism on analytic rings. In light of our intuition that $D(A)$ is more important than $A^\vartriangleleft$, this will mostly be done categorically.
\begin{definition}
	For a morphism $f\colon\op{Sp}B\to\op{Sp}A$ of analytic rings, we define the $*$-pushforward as the underlying map $f_*\colon D(B)\to D(A)$, and its right adjoint is the $*$-pullback $f^*$.
\end{definition}
For the remaining functors, we need classes of maps $I$, $P$, and $E$. In short, $I$ should consist of open embeddings, $P$ should consist of proper maps, and $E$ should be $!$-able maps. Notably, following Nagata compactification, $E$ is the same as composites of a map in $I$ with a map in $P$.

Let's start with $P$.
\begin{definition}
	A map $f\colon A\to B$ of analytic rings is \textit{proper} if and only if

	It is equivalent to require that $D(B)\cong\op{Mod}_{B^\vartriangleleft}D(A)$.
\end{remark}

	If $f\colon A\to B$ is proper, then the $*$-pullback map $D(A)\to D(B)$ is just $-\otimes_{A^\vartriangleleft}B^\vartriangleleft$.
\end{remark}

	Fix a proper map $f\colon A\to B$ of analytic rings. Then the right adjoint of $f^*\colon D(A)\to D(B)$ is denoted $f_!\colon D(B)\to D(A)$.
\end{definition}
\begin{remark}
	One can check that base-change and the projection formula both hold for $f_!$ in this setting.
\end{remark}
We now turn to $I$. Here is the analytic example.
\begin{example}
	Let $j\colon X\to Y$ be an open embedding. Then the functor $j^*$ on constructible sheaves admits a fully faithful left adjoint, and it satisfies the projection formula
	\[j_!(j^*A\otimes B)=A\otimes j_!B.\]
\end{example}
\begin{remark}
	If one works with quasicoherent sheaves instead of constructible sheaves, then everything appears backwards.
\end{remark}
\begin{remark}
	There is a similar calculation that can be done for closed embeddings, which have fully faithful right adjoints.
\end{remark}
Let's turn this into a definition.
\begin{definition}
	A map $f\colon\mc C\to\mc D$ of stable categories is \textit{open} if and only if it admits a fully faithful left adjoint and satisfying some projection formula.
\end{definition}
\begin{example}
	Let $A$ be an idempotent algebra in $\mc C$, meaning that $A\otimes A\cong A$. Then the forgetful functor $\mathrm{Mod}_A(\mc C)\to\mc C$ is fully faithful and admits the adjoint given by the tensor product. It turns out that the adjoint construction provides all the closed embeddings.
\end{example}
A similar example works for open embeddings.
\begin{definition}
	A map $j\colon A\to B$ of analytic rings is \textit{open} if and only if $j^*\colon D(A)\to D(B)$ is open. By definition, we are provided with a left adjoint $j_!\colon D(B)\to D(A)$.
\end{definition}
At long last, we have enough functors to state a theorem.
\begin{theorem}
	The functors $(\otimes,f_*,f_!)$ defines a three-functor formalism satisfying the projection formula and base-change.
\end{theorem}
This is not totally formal. For example, one needs some base-change property for proper and open maps. However, we will not explicate any of these checks.

We close our discussion by defining an analytic stack.
\begin{definition}

\end{definition}

\end{remark}

\subsection{The Analytic Ring \texorpdfstring{$\ZZ[T]_\blacksquare$}{ Z[T] box}}
This second part of the talk was given by Tong. The goal of the second part of the talk is to get some intuition about the analytic ring $\ZZ[T]_\blacksquare$. Recall the following definition.
\begin{definition}
	A condensed abelian group $A$ is \textit{solid} if and only if the map ${\id}-1$ is an isomorphism on $\op{Hom}_\ZZ(P,M)$, where $P=\ZZ[\NN\cup\{\infty\}]/\ZZ[\{\infty\}]$.
\end{definition}
We now introduce $\ZZ_\blacksquare[T]$, which is almost $\ZZ[T]_\blacksquare$.
\begin{notation}
	Define the analytic ring $\ZZ_\blacksquare[T]$ to consist of the ring $\ZZ[T]$ along with the subcategory $D(\ZZ_\blacksquare[T])\subseteq D(\ZZ[T])$ consisting of the solid modules.
\end{notation}
Approximately speaking, $\ZZ_\blacksquare[T]$ should be like an affine line over $\ZZ_\blacksquare$. We would like to construct a unit disk over $\ZZ_\blacksquare$. In classical rigid analytic geometry, this is done over $\QQ_p$ via the Tate algebra $\QQ_p\langle T\rangle$ of series $\sum_na_nT^n$ whose coefficients tend to zero. Thus, we expect that
\[\ZZ[T]_\blacksquare\otimes_{\ZZ_\blacksquare}\QQ_p\cong\QQ_p\langle T\rangle.\]
For example, one would expect that $\ZZ[T]_\blacksquare$ still has underlying ring $\ZZ[T]$, and we will just change the underlying category. Also taking motivation from our remark about $\QQ_p\langle T\rangle$, we have the following definition.
\begin{definition}
	Define the pair $\ZZ[T]_\blacksquare$ to have underlying ring $\ZZ[T]$ and category $D(\ZZ[T]_\blacksquare)$ consisting of those solid $M\in D(\ZZ[T])$ for which any nilsequence $\{a_n\}$ in $M$ makes $\sum_na_nT^n$ convergent. This latter condition means that
	\[({\id}-T)\colon\op{Hom}_{\ZZ_\blacksquare[T]}(P',M)\to\op{Hom}_{\ZZ_\blacksquare[T]}(P',M)\]
	is an isomorphism, where $P'=P\otimes_\ZZ\ZZ_\blacksquare[T]$.
\end{definition}

	is exact. Thus, $M\in D(\ZZ_\blacksquare[T])$ lives in $D(\ZZ[T]_\blacksquare)$ if and only if $\op{Hom}_{\ZZ_\blacksquare[T]}(\ZZ((1/T)),M)=0$.

\subsection{Overconvergent Elements}
Last time, we defined the idempotent algebra $\QQ_p\langle\NN[S]\rangle_{\le r}$.
\begin{definition}
	For each $A\in\op{Ring}_{\QQ_p}$, define the condensed subring $A^{\le r}\subseteq A$ for the subring given by sending profinite sets $T$ to
	\[\op{Mor}_{\mathrm{Ring}_{\QQ_p}}(\QQ_p\langle\NN[S]\rangle_{\le r},A)\subseteq A(T).\]
	We define the \textit{nilradical} to be $\op{Nil}^\dagger A\coloneqq A^{\le0}$. While we're here, we define $A^{<r}\coloneqq\bigcup_{r'<r}A^{\le r'}$.
\end{definition}
\begin{remark}
	It turns out that $A^{\le r}$ as defined is a sheaf on $\mathrm{ProFin}$. (The prefix ``hyper'' is required because everything is derived.)
\end{remark}
\begin{remark}
	Given a ring $R$, one can define $R^\times$ as $\op{Hom}(\ZZ[T,1/T],R)$. Thus, we may think of the ring $\ZZ[T,1/T]$ as testing units. Analogously, $\QQ_p\langle\NN[S]\rangle_{\le r}$ tests for size bounded by $r$.
\end{remark}
\begin{lemma}
	Fix $A\in\op{Ring}_{\QQ_p}$. For any $r\ge0$, the condensed ring $A^{\le r}$ is solid.
\end{lemma}
\begin{proof}
	Last time, we realized that $\QQ\langle\NN[S]\rangle$ as a Tate algebra with enough variables after extending $\QQ$. We can do a similar trick this time, but to keep track of the power-bounding, we need to do an integral variant. Namely, one has
	\[\ZZ_p\left[p^{\QQ^+}\right]\otimes_{\ZZ_p}A^{\le r}=\bigcap_{\substack{a\in\QQ\\p^{-a}\le r}}p^{-a}\left(\ZZ_p\left[p^{\QQ^+}\right]\otimes_{\ZZ_p}A^\circ\right).\]
	Now, $A^\circ$ is solid, so each disk is solid, so the entire intersection is solid, so the retract $A^{\le r}$ is solid.
\end{proof}
\begin{example}
	Let $A$ be a Banach $\QQ_p$-algebra. Then $A^{\le1}=A^\circ$, which we recall is the collection of power-bounded elements.
\end{example}
\begin{example}
	Take $A\coloneqq\AA_p\langle\NN[S]\rangle$, which is the Tate algebra with $S$ as variables. Then $A^{\le1}=\ZZ_p\langle\NN[S]\rangle$.
\end{example}
\begin{proposition} \label{prop:addition-multiplication-bounded}
	For nonnegative $r$ and $s$, addition defines a map $A^{\le r}\times A^{\le s}\to A^{\le\max\{r,s\}}$, and multiplication defines a map $A^{\le rs}$.
\end{proposition}
\begin{proof}
	Omitted.
\end{proof}
\begin{corollary}
	Let $A\in\op{Ring}_{\QQ_p}$ be bounded. Then $\op{Nil}^\dagger A$ is an ideal of $A$.
\end{corollary}
\begin{proof}
	Setting $r=s=0$ in \Cref{prop:addition-multiplication-bounded} quickly completes the proof. To be technical, we should check that $A=\bigcup_rA^{\le r}$. To show this, note that $A^\circ\subseteq A^{\le1}$ by definition of $A^{\le1}$. But $A^{\le1}\subseteq p^{-1}A^\circ$ because $A^{\le1}$ is an intersection of all disks of radius greater than one. It follows that $A$, which is $A^\circ[1/p]$ can be written as $\bigcup_rA^{\le r}$ by moving the powers of $p$ around.
\end{proof}
\begin{definition}
	Fix a bounded $A\in\op{Ring}_{\QQ_p}$. Then $A$ is \textit{$\dagger$-reduced} if and only if $\op{Nil}^\dagger(A)=0$. In general, we define the \textit{$\dagger$-reduction} as $A^{\dagger\textrm{-red}}\coloneqq A/\op{Nil}^\dagger A$.
\end{definition}

\subsection{Uniform Rings}
Intuitively, the uniform ring is analogous to taking a $p$-adic completion.
\begin{definition}
	Fix a bounded $A\in\op{Ring}_{\QQ_p}$. Then define the \textit{uniform ring} to be
	\[A^u\coloneqq\left(\lim_{r>0}A^{\le1}/A^{\le r}\right)\left[\frac1p\right].\]
	We say that $A$ is \textit{uniform} if and only if the natural map $A^{\le1}[1/p]\to A^u$ is an isomorphism.
\end{definition}
\begin{remark}
	Intuitively, taking the inverse limit is a $p$-adic completion. Roughly speaking, it will turn out to be the completion of $A^{\dagger\textrm{-red}}$.
\end{remark}
\begin{example}
	Fix a Banach $\QQ_p$-algebra $A$. Then $A^{\le1}=A^\circ$, so $A$ is uniform if and only if $A^\circ$ is $p$-adically complete. Here is a non-example: note $A\coloneqq\QQ_p[t]/\left(t^2\right)$ has $A^\circ=\ZZ_p\oplus\QQ_pt$, which is not $p$-adically complete because $\QQ_pt$ dies upon taking $p$-adic completion.
\end{example}
\begin{example}
	Take $A\coloneqq\QQ_p\langle\NN[S]\rangle_{\le1}$. Note that there is an inclusion $A\subseteq\QQ_p\langle\NN[S]\rangle$: on a test algebra $B\in\op{Ring}_{\QQ_p}$, this is given by the inclusions $B^\circ\into B^{\le1}$. This yields an inclusion $A^{\le1}\into\ZZ_p\langle\NN[S]\rangle$, and it turns out that
	\[A^{\le1}=A\cap\ZZ_p\langle\NN[S]\rangle.\]
	Thus, $A^{\le1}/p^n=\ZZ/p^n[\NN[S]]$, so taking the uniform completion yields $A^u=\QQ_p\langle\NN[S]\rangle$.
\end{example}
Here are some basic properties.
\begin{remark}
	It turns out that $A^u\cong\left(A^{\dagger\textrm{-red}}\right)^u$. Basically, this should follow from the definition and \Cref{rem:pushout-red}, basically pulling out the reduction.
\end{remark}
\begin{proposition} \label{prop:uniform-properties}
	Fix bounded $A\in\op{Ring}_{\QQ_p}$.
	\begin{listalph}
		\item The following is a pushout square in $D(\ZZ_p)$ for any $r\ge0$.
		% https://q.uiver.app/#q=WzAsNCxbMCwwLCJBXntcXGxlIHJ9Il0sWzEsMCwiQV57dSxcXGxlIHJ9Il0sWzAsMSwiQSJdLFsxLDEsIkFedSJdLFsyLDNdLFswLDFdLFsxLDNdLFswLDJdXQ==&macro_url=https%3A%2F%2Fraw.githubusercontent.com%2FdFoiler%2Fnotes%2Fmaster%2Fnir.tex
		\[\begin{tikzcd}[cramped]
			{A^{\le r}} & {A^{u,\le r}} \\
			A & {A^u}
			\arrow[from=1-1, to=1-2]
			\arrow[from=1-1, to=2-1]
			\arrow[from=1-2, to=2-2]
			\arrow[from=2-1, to=2-2]
		\end{tikzcd}\]
		\item One has $A^{u,\le1}=\lim_{r>0}A^{\le1}/A^{\le r}$, so $\left(A^u\right)^u=A^u$.
		\item The ring $A^u$ is $\dagger$-reduced.
		\item Choose $f\in A$. Then $f$ is invertible if and only if its image in $A^u$ is invertible.
	\end{listalph}
\end{proposition}
\begin{remark}
	By setting $r=0$ in (a), we see that $A^{\dagger\textrm{-red}}\to A^u$ is injection.
\end{remark}
\begin{remark}
	The fact that $\left(A^u\right)^u=A^u$ means that $(-)^u$ is left adjoint to the inclusion $\mathrm{Ring}_{\QQ_p}^u\subseteq\mathrm{Ring}_{\QQ_p}^b$.
\end{remark}

\subsection{Gelfand Rings}
We are now allowed to make a definition.
\begin{definition}[Gelfand]
	A bounded ring $A\in\op{Ring}_{\QQ_p}$ is \textit{Gelfand} if and only if $A/A^{\le1}$ is discrete. Let $\op{GelfRing}_{\QQ_p}$ be the subcategory of Gelfand rings.
\end{definition}
\begin{remark}
	Being discrete is closed under filtered colimits, subquotients, and extensions. Thus, a ring $A$ is Gelfand if and only if any (equivalently, all) of $A/A^{\le r}$, $A/A^{<r}$, $A^{\le r}/A^{\le s}$ for $r>s$, etc. is discrete.
\end{remark}
\begin{example}
	If $A$ is a Banach $\QQ_p$-algebra, then $A^{\le1}=A^\circ$, which is open, so $A/A^{\le1}$ is discrete, so $A$ is Gelfand.
\end{example}
\begin{example}
	Consider $A\coloneqq\QQ_p\langle\NN[S]\rangle_{\le1}$. Then $A$ is Gelfand if and only if $A^{\le1}/p$ is discrete, which is $\FF_p[\NN[S]]$. But
	\[\FF_p[\NN[S]]=\bigoplus_n\FF_p[S^n/\Sigma_n].\]
	If $S$ is infinite, then the terms have infinite products of $\FF_p$s, which fails to be discrete, so $A$ fails to be Gelfand. But if $S$ is finite, then the terms are finite products of $\FF_p$, which is discrete.
\end{example}
Here is a better way to test to be a Gelfand ring.
\begin{lemma}
	Fix a bounded ring $A\in\op{Ring}_{\QQ_p}$. Then $A$ is Gelfand if and only if $A^u$ is a Banach $\QQ-p$-algebra.
\end{lemma}
\begin{proof}
	By \Cref{prop:uniform-properties}, we see $A/A^{\le1}=A^u/A^{u,\le1}$. Thus, we may assume that $A$ is uniform. Now, $A$ is a Banach $\QQ_p$-algebra if and only if $A^{\le1}/p$ is discrete. For example, the reverse direction follows because one basically tries to reconstruct $A$ from $A^{\le1}/p$ by taking some inverse limits, which means that $A$ is a purely classical object and hence a Banach $\QQ_p$-algebra.
\end{proof}
\begin{example}
	Recall $\left(\QQ_p\langle t\rangle_{\le1}\right)^u=\QQ_p\langle t\rangle$. Thus, $\QQ_p\langle t\rangle_{\le1}$ is Gelfand.
\end{example}
\begin{remark}
	One can use this to check that $\op{GelfRing}_{\QQ_p}$ is closed under colimits. Because $(-)^u$ is left adjoint to the forgetful functor, we find that $(\colim A_i)^u$ is isomorphic to $(\colim A_i^u)^u$. The latter is now a colimit of Banach $\QQ_p$-algebras and hence a Banach $\QQ_p$-algebra.
\end{remark}

\subsection{The Berkovich Spectrum}
Here is our construction.
\begin{definition}[Berkovich spectrum]
	Fix a Banach ring $(B,\left|\cdot\right|)$. Then the \textit{Berkovich spectrum} $\mc M(B)$ is the set of multiplicative seminorms $\norm\cdot\colon B\to\RR_{\ge0}$ dominated by $\left|\cdot\right|$. Then $\mc M(B)\subseteq\prod_{b\in B}[0,\left|b\right|]$, and we give $\mc M(B)$ the subspace topology. For a Gelfand ring $A$, we define $\mc M(A)\coloneqq\mc M(A^u)$.
\end{definition}
\begin{remark}
	One can cut out $\mc M(B)$ from $\prod_{b\in B}[0,\left|b\right|]$ by some non-strict inequalities, so it is a compact Hausdorff space.
\end{remark}
\begin{example}
	Take $A=\CC_p\langle t\rangle$. Then $\mc M(A)$ is a cofiltered limit of finite trees.
	\begin{itemize}
		\item Type I points: for each $x\in\OO_{\CC_p}$, there is a seminorm $f\mapsto\left|f(x)\right|$.
		\item Type II points: given $x\in\OO_{\CC_p}$ and $r\in[0,1]\cap p^\QQ$, there is a seminorm $f\mapsto\sup\{\left|f(x')\right|:\left|x'-x\right|\le r\}$. Note that one gets the same seminorm if $x$ is moved to any other point in the disk $\overline{B(x,r)}$.
		\item Type III points: given $x\in\OO_{\CC_p}$ and $r\in[0,1]\setminus p^\QQ$, one can write down the same formula. These points connect type II points (and type I points).
		\item Type IV points: given a decreasing sequence of nonempty disks $\{D_n\}$ for which $\bigcap_nD_n=\emp$, one can define the seminorm $f\mapsto\inf_n\sup_{x\in D_n}\left|f(x)\right|$.
	\end{itemize}
	Type I and type IV points are ``leaves'' of the tree. Note that in type IV, the radii of the disks must tend to a positive number, so they are arguably not at the ``bottom.''
\end{example}

\subsection{Fredholm Rings}
Fix a presentable symmetric monoidal stable $\infty$-category $\mc C$.
\begin{definition}
	Fix a symmetric monoidal stable category $\mc C$. Then the subcategory of \textit{perfect objects} is the stable subcategory generated by $1$, finite limits, shifts, and retracts.
\end{definition}
\begin{remark}
	Note that this subcategory is also closed under finite colimits by stability.
\end{remark}
\begin{definition}
	Fix a symmetric monoidal stable category $\mc C$. Then the subcategory of \textit{dualizable objects} consists of those $c\in\mc C$ admitting $c^\lor\in\mc C$ and evaluation $\op{ev}\colon c\otimes c^\lor\to1$ and co-evaluation maps $\op{coev}\colon c^\lor\otimes c\to1$ satisfying some conditions. Namely,
	\[c=1\otimes c\to (c\otimes c^\lor)\otimes c=c\otimes (c^\lor\otimes c)\to c\otimes1=c\]
	is the identity, and similarly for $c^\lor$.
\end{definition}
\begin{example}
	The unit is self-dualizable.
\end{example}
\begin{remark}
	It turns out that perfect objects are always dualizable. In $D(R)$ where $R$ is a classical ring, the converse holds.
\end{remark}
Today, we are working with some general analytic rings $A=\left(A^\vartriangleleft,D(A)\right)$.
\begin{definition}
	An analytic ring $A$ is \textit{Fredholm} if and only if dualizable objects are perfect in $D(A)$.
\end{definition}
\begin{remark}
	Recall that $A^\vartriangleleft\in D(A)$, so the perfect objects in $D(A^\vartriangleleft)$ live in $D(A)$. Thus, being Fredholm is equivalent to saying that dualizable objects in $D(A)$ all come from the smaller algebraic category $D(A^\vartriangleleft(\mathrm{pt}))$.
\end{remark}
\begin{example}
	If $A$ comes from a complete Huber pair, then $A$ is Fredholm.
\end{example}
\begin{example}
	If $A$ is a Gelfand ring, then $A$ is Fredholm.
\end{example}
\begin{nex}
	The condensed ring $A=\QQ_p[t]$ fails to be Fredholm. Roughly speaking, the problem is that $A$ is too big. Define $P\coloneqq\left(\prod_\NN\ZZ_p\right)[1/p]$, which lives in $D(\QQ_p)$. We now claim that
	\[M\coloneqq\op{cofiber}\left(1-t\left(1,p,p^2,\ldots\right);P\otimes_{\QQ_p}\QQ_p[t]\right)\]
	exhibits our counterexample. The moral is that the endomorphism $\left(1,p,p^2,\ldots\right)$ is trace class. One can use some functional analytic arguments to show that $M$ is dualizable. However, $M$ has nontrivial pullback to the fiber $t=p^{-n}$ for all $n\in\NN$, so it has fibers going off to infinity, so it fails to be perfect.
\end{nex}

\subsection{More on the Berkovich Spectrum}
Last time, we introduced the Berkovish spectrum of a Gelfand ring $A$.
\begin{definition}
	Fix a Gelfand ring $A$. Given elements $f_1,\ldots,f_n,g\in A(\mathrm{pt})$ which generate $A(\mathrm{pt})$ as an ideal (in $\pi_0$). Then we define the associated closed rational subspace
	\[\mc M\left(\frac{f_1,\ldots,f_n}g\right)\coloneqq\left\{\left|\cdot\right|\in\mc M(A^u):\left|f_i\right|\le\left|g\right|\ne0\text{ for each }i\right\}.\]
\end{definition}
\begin{proposition}
	Fix a Gelfand ring $A$. Suppose $Z\subseteq\mc M(A)$ is rational closed. Then there is a Gelfand idempotent $A$-algebra $A_Z$ such that any map $A\to B$ of Gelfand rings extends to $A_Z\to B$ if and only if the associated topological map $\mc M(B)\to\mc M(A)$ land in $Z$.
\end{proposition}
\begin{proof}
	Write $Z=\mc M(f_1,\ldots,f_n/g)$. Then define $A_Z\coloneqq A\langle t_1,\ldots,t_n\rangle_{\le1}/(gt_i-f_i)_i$.
\end{proof}
\begin{remark}
	One can check that $\mc M(A_Z)=Z$.
\end{remark}
There is a more categorical way to work with such spaces.
\begin{definition}[smashing spectrum]
	Fix a stable category $\mc C$. Then the \textit{smashing spectrum} $\op{sm}\mc C$ is the collection of idempotent algebras in $\mc C$.
\end{definition}
\begin{remark}
	This is a locale, which is some kind of weakening of a Grothendieck topology.
\end{remark}
\begin{example}
	If $A$ is a Noetherian ring, then $\op{sm}D(R)$ is isomorphic to $\Spec(R)\opp$ as locales. However, this is rarely true outside the Noetherian setting.
\end{example}
\begin{remark}
	Fix a Gelfand ring $A$. Then there is a unique natural map of locales $\op{Sm}D(A)\to\mc M(A)$ extending $Z\mapsto A_Z$. Here, being a map of locales means that closed subsets have pre-image given by closed sets.
\end{remark}
\begin{notation}
	Fix a profinite set $S$. Then we define $S_{\mathrm{Betti}}$ to be the animated spectrum of $C_{\mathrm{cts}}(S,\ZZ)$.
\end{notation}
\begin{remark}
	By taking colimits, this construction extends to a functor $(-)_{\mathrm{Betti}}$ from condensed animated modules to animated stacks.
\end{remark}
\begin{remark}
	Fix a Gelfand ring $A$. When $\mc M(A)$ is metrizable and finite-dimensional, then there is a natural map
	\[\op{AnSpec}A\to\mc M(A)_{\mathrm{Betti}}\times_{\op{AnSpec}\ZZ}\op{AnSpec}\QQ_{p\blacksquare}\]
	which satisfies universal $!$-descent. The hypotheses on $\mc M(A)$ are needed to be able to map into it (as some kind of compact Hausdorff space).
\end{remark}

\subsection{Gelfand Stacks}
We now switch to Jeremy.
\begin{definition}[separable]
	A Gelfand ring $R$ is \textit{separable} if and only if $R^u$ has a countable dense subset.
\end{definition}
\begin{remark}
	This is equivalent to saying that $R^u$ is $\omega_1$-compact in Banach $\QQ_p$-algebras. Roughly speaking, separability is a finiteness property.
\end{remark}
\begin{definition}[Gelfand stack]
	Define the category of \textit{Gelfand stacks} to be the category of analytic stacks on the opposite category of Gelfand rings.
\end{definition}
Notably, the finiteness condition lives on the uniform completion, which intuitively erases any (topologically) nilpotent fuzz.

These Gelfand stacks are supposed to contrast with arc stacks.
\begin{definition}[arc cover]
	A map $A\to B$ of perfectoid Tate rings over $\QQ_p$ is an \textit{arc cover} if and only if $\mc M(B)\to\mc M(A)$ is surjective.
\end{definition}
\begin{definition}[separable]
	A Tate ring $A$ is \textit{separable} if and only if $A^\circ/\varpi$ is countable, where $\varpi\in A$ is a uniformizer.
\end{definition}
\begin{remark}
	Again, an affine perfectoid $\QQ_p$-algebra $A$ is separable if and only if it is $\omega_1$-compact.
\end{remark}
\begin{definition}
	The category of \textit{arc stacks} is the category of hypersheaves on the arc site of the category of $\op{AffPerfd}\opp_{\omega_1}$.
\end{definition}
\begin{remark}
	Each perfectoid Tate algebra $A$ admits an arc cover $A\to B$ where $B$ is totally disconnected (i.e., $\mc M(B)$ is profinite).
\end{remark}
Here is our main construction, which we will return to next week.
\begin{proposition}
	Fix a separable Gelfand ring $A$. Define the functor $\op{Mor}_{\mathrm{GelfRing}}(A,-)$, restricted to totally disconnected objects in affinoid perfectoid $\omega_1$-compact rings. Then this functor is an arc stack.
\end{proposition}
Taking descent produces the following.
\begin{corollary}
	There is a functor $(-)^\diamondsuit\colon\mathrm{GelfStk}_{\QQ_p}\to\mathrm{ArcStk}_{\QQ_p}$.
\end{corollary}
This functor is supposed to be destructive, getting rid of nilpotence in some sense. Next time, we will show that $(-)^\diamondsuit$ has a right adjoint $(-)^{\mathrm{DR}}$.
